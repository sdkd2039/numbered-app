# معدودات لنظام iOS

مشروع iOS أصلي مستقل يحافظ على تطبيق Android دون تغييره.

## المزايا الحالية
- تطبيق SwiftUI باللغة العربية واتجاه RTL.
- الأذكار: الصباح والمساء والمنوعة، التنقل، العداد وشريط التقدم.
- المتبقي: المناسبات القادمة والتاريخ الهجري والعد التنازلي بالأيام والساعات والدقائق.
- WidgetKit Extension بويدجت للأذكار وآخر للمناسبات.
- أزرار تفاعلية للزيادة والانتقال إلى الذكر التالي عبر App Intents.

## الإعداد
افتح `Numbered.xcodeproj` على macOS باستخدام Xcode.
1. عدّل Bundle IDs في Build Settings إلى معرفات فريدة لك.
2. فعّل App Groups لكلا الهدفين، مع المجموعة `group.com.sutstudio.numbered` أو غيّرها في `Shared/AppGroup.swift`.
3. فعّل Automatically manage signing واختر Team.
4. أضف ملفات CSV من `Shared/Resources` إلى موارد هدف التطبيق وهدف الويدجت؛ يجب تضمينها في الاثنين.
5. ابنِ الهدفين على iPhone Simulator ثم على جهاز حقيقي.

يتطلب بناء iOS وجود macOS وXcode. لا يمكن إخراج IPA صالح للتثبيت أو النشر دون إعداد توقيع Apple المناسب. واجهة WidgetKit يحدّ النظام من تردد تحديثها؛ لذلك لن تتغير كل دقيقة باستمرار كما في شاشة التطبيق.
